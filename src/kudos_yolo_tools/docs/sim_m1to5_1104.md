# 2026 시뮬에서 미션 1~5 YOLO 한 번에 (11/4)

목표: Gazebo 2026 맵(KUDOS_Autorace2026_Gazebo)에서 미션 1~5 물체를 모델 하나로 인식하고,
`/perception/mission_objects` 로 판단(세진)에 넘기는 것까지 확인.

| 미션 | 보내는 상수 | 시뮬 데이터 |
|---|---|---|
| M1 신호등 | TRAFFIC_LIGHT (+light_color), CROSSWALK | 신호등, 횡단보도 |
| M2 갈림길 | SIGN_A / SIGN_B | 갈림길 표지판 (A 실행 + B 실행) |
| M3 보행자 | PEDESTRIAN_SIGN, CROSSWALK | 보행자 표지판, 횡단보도 |
| M4 주차 | PARKING_SIGN, LIMO | 주차 표지판, 주차칸 옆 LIMO |
| M5 서행 | BUMP_SIGN (시뮬), SLOW_SIGN (실사만) | 방지턱 표지판 — **시뮬 맵에 서행 표지판 없음** |

새 파일
- `scripts/world_targets.py` — world 파일을 읽어 라벨 대상·순간이동 구역·점검 지점을 만든다 (ROS 불필요)
- `scripts/mission_check.py` — 미션 물체 앞으로 순간이동하며 인식 결과를 표로 (판정 OK/약함/없음, 거리 오차, 신호등 색)
- `config/dataset_v2_full.yaml` — 학습 설정
- `scripts/bag_to_images.py`, `scripts/tl_check.py` — 실차 bag → 사진, 신호등 미리 라벨·색 정확도
- yolo_detector_node: 신호등 모양 검사(광고 모니터 대응). 화면 속 그림 신호등·원은 비율·실제 높이로 걸러냄
- collect_data_v2.launch.py: `config_dir:=` 인자, viewpoint_sampler: 경기장 밖 순간이동 금지(bounds)

## 3. 신호등 실사 (수집 돌아가는 동안)
LIMO 켜고 핫스팟 연결 후:
```
mkdir -p ~/yolo_data/real_m1 && cd ~/yolo_data/real_m1
scp -r wego@172.20.10.4:~/bags .
S=~/26contest/src/kudos_yolo_tools/scripts
for b in tl_red tl_red2 tl_off tl_ad tl_red_test; do python3 $S/bag_to_images.py bags/$b img/$b --every 0.5; done
python3 $S/tl_check.py ~/yolo_data/v2/models/best_sim_v2_1029.pt img/tl_red img/tl_red2 img/tl_off img/tl_ad img/tl_red_test
```
출력 표(검출률·색 정답률)와 `img/*/_check/` 사진 몇 장(NOBOX_, WRONG_)을 Claude 에게.
`labels/` 는 초안이라 바로 학습에 넣지 않음 (NOBOX 사진은 빈 라벨, tl_ad 는 화면 속 신호등에 박스가 쳐졌을 수 있음).

## 4. 나누기 → 불리기 → 학습 (약 15~20분)

## 5. Gazebo 점검표 (미션 1~5)
차를 움직이는 노드(판단·제어·teleop)는 끈 상태에서:
```
# 터미널 2
ros2 launch kudos_yolo_tools yolo_detector_sim.launch.py weights:=$HOME/yolo_data/v2/models/best_sim_full_1104.pt
# 터미널 3
ros2 run kudos_yolo_tools mission_check.py --ros-args -p use_sim_time:=true
```
지점마다 OK / 약함 / 없음, x_m 과 기대 거리 차이(cm), 신호등 색, 잘못 나온 다른 클래스가 나온다.
끝에 표 + `~/yolo_data/v2/mission_check_*.csv`. 이 표를 팀(세진)에게 공유.
- 횡단보도 오차 허용 max(5cm, 10%) — 3cm 정지라 가장 엄격. 0.25m 에서 '위치 없음'은 정상(화면 하단에 닿음 → 판단이 odom)
- 갈림길은 Gazebo 를 띄운 A/B 와 다른 쪽이 나오면 '없음' + 다른 클래스에 SIGN_A/B 로 표시됨

## 판단(세진)에 전할 것
- 시뮬 M5 진입은 BUMP_SIGN 으로 (SLOW_SIGN 은 시뮬에 없음, 실차에서만 나옴)
- 신호등은 모양 검사를 통과한 1개만 보냄. 광고 화면 신호등이 걸러지면 yolo 노드 로그에 '신호등 후보 버림'
- CROSSWALK 은 EMA 없음, 화면 하단에 닿으면 position_valid=false
